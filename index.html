Personal project · Formula 1 analytics

Undercut: race-strategy decision support built on live F1 timing data

  • React
  • Python
  • Forecasting
  • Monte Carlo
  • KPI scorecard
  • CI/CD
~30Kstrategies searched per scenario
2,000simulated races per plan
Live app Code

Problem

F1 strategy is a decision under uncertainty: when to pit and on which tyres, with a random safety car that can make or break the call. Public tools show the data but don't recommend anything.

What I did

Built a lap-by-lap race model fitted to real data and backtested on unseen races. Added a Monte Carlo simulation for safety-car risk, an optimiser that searches every legal plan, a one-page strategy brief, and an operations scorecard for every team's pit crew.

Result

A live tool with executive-style briefs, KPI scorecards and risk-adjusted recommendations, backed by automated tests. Forecasting and scenario planning, applied to a sport I follow closely.
